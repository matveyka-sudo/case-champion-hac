# Сверка пользовательских данных с ТЗ · 09.11.2026

Основание: восемь PDF из принятого пакета «от моти», прежде всего PRODUCT_SPEC 2026-11-08.1 / FORMULAS v3; apps/api/docs/frontend-integration-handoff.md и contracts/generated/openapi.json. Методика не пересматривается. Изменено представление данных, HTTP/DTO не менялись.

| Ответ API | Что остаётся в интерфейсе | Что используется только внутри связки |
|---|---|---|
| capabilities / territories | Территории, районы, режимы трафика, категории, принятые грузовые профили и доступность расчёта | Оpaque ID территорий/профилей, версии и inventory без выдуманного покрытия |
| jobs / cancel | Очередь, расчёт, ошибка, отмена; кнопка отмены | job_id, request_id, задержки polling |
| analyses | Индексы, исходные показатели и составляющие пути, выбранные условия, население с годом/методом, доступные объекты, последний обратный рейс, карта и источники | analysis_id, snapshot_id, result_hash, версии, reference_ids, calculation_kind и технические операнды |
| explanation | Объяснение, связанные сохранённые показатели, источники, ограничения и идеи | IDs модели/метрик, хэш результата, технический reason_code |
| scenarios / runs | Разрешённое предложение, условия/ограничения, проверка только кнопкой, до/после, ухудшения и охват | scenario_id, overlay_graph_id, hashes и прочие служебные поля |

Численные показатели не отсекаются по случайному списку названий: их семантика определяется сервером. Удалены отдельные блоки технических операндов и версий, а не бизнес-метрики. counts/last_returns остаются, потому что прямо требуются ТЗ. Пустой блок дополнительных показателей не показывается. Неизвестное/неприменимое/частичное/ожидающее значение различаются и не обнуляются.

ID объектов больше не подставляются вместо их названий: используются серверное имя или нейтральный тип объекта. Enum режима/статуса/участка маршрута переведён в понятную подпись. Профиль груза выбирается по прежнему серверному profile_id, но показывается через продукт, срочность, обработку, температуру и габариты. Схема пути остаётся явно обозначенной; время движения груза не подписывается полным временем доставки.

В демо убраны лишняя городская строка расстояния по прямой, неподдержанный самостоятельный класс «Сырьё» и переключатель «Скоропортящийся». Маркировка демо сохранена. Устаревшие подписи о неутверждённых формулах/порогах заменены на фактическое отсутствие расчёта в демонстрации; принятая методика не объявляется отложенной. Источники/даты, карта, четыре направления, категории и основные сценарии сохранены. Исключённые ТЗ цены, такси, каршеринг, однодневные поездки, конструктор сценариев и отдельный экран сравнения не добавлялись.

Проверки UI дополнены отсутствием в карточке/чате analysis ID, result hash, overlay ID и dependency job ID; при этом готовый индекс и pending дополнительного показателя сохраняются.
