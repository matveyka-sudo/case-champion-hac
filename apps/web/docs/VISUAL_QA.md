# Перенос HTML → React: визуальная проверка

Исторический отчёт переноса HTML. С 09.11.2026 текущее приложение находится
в `apps/web/`; упоминания прежнего пути ниже описывают исходную проверку.

Эталон: пользовательский `waydex-prototype/index.html`, хэш в `src/mocks/source.json`. Исходник не изменялся. CSS, тексты лендинга, фотографии, размеры панелей, брейкпоинты, keyframes и scroll-progress перенесены из него. Числовые данные извлечены в фиксированные fixtures, не пересчитываются транспортной формулой.

## Метод проверки

Оригинал обслуживался локально на 8086, React — на 5176. Chromium, одинаковые viewport: 1440×900, 1280×800, 768×1024, 390×844. Для статического сопоставления в обеих страницах включён reduced motion, ожидались шрифты. Сняты лендинг целиком, Россия, Москва, ночь, пассажирская пара и городские грузы. Сеть тайлов/шрифтов может различаться по скорости между прогонами: это не пиксельный golden-тест карты.

Скриншоты текущей сессии находятся вне репозитория в `/tmp/waydex-qa/` (пары `reference-*` и `react-*`); файлы временные. Для повторения используйте исходную папку и те же viewport/условия. Регрессионные сценарии закреплены в `e2e/atlas.spec.ts`.

## Исправлено при сравнении

- SVG linearGradient и React-атрибуты, порядок глобальных стилей.
- Начальная команда home больше не переопределяет масштаб городского примера.
- Сохранена проекция России, auto-fit к паре, размер подписей/узлов при zoom и направление дуги.
- Карточка не навязывает desktop-отступ мобильной строке статуса.
- Высота mobile sheet измеряется, легенда остаётся над ней.
- Карта изолирована по stacking context: меню состояний доступно над overlays.
- Безопасный чат/запросы не публикуют ответ для устаревшего контекста.
- Нагрузка лендинга отделена от загрузки демо-атласа; крупный JSON не компилируется в JS.

## Намеренные технические отличия от прототипа

- Активный модуль `frontend/` согласно актуальному AGENTS/OWNERSHIP; `apps/web/` не менялся.
- Формула индекса/H не исполняется в клиенте: утверждённые визуальные демо-значения сохранены как fixtures. Пояснение в подробностях карточки уточнено, чтобы не выдавать формулу за принятую.
- Даты поля приведены к задокументированному диапазону 1–30 ноября; в HTML min/max поля расходились с его validation.
- Добавлены отмена запросов, focus management мобильных панелей и обработка настоящего сбоя загрузки local fixtures.
- Режим pending нейтрализует расчётный слой, не демонстрируя точный индекс до утверждения методики.
- Локальные геоданные вместо зависимости от CDN; городские тайлы и Google Fonts по-прежнему внешние.

Проверка внешнего API, engine, реальной LLM и эксплуатационной пригодности сценария вне этого переноса. Нет утверждения о 100% попиксельном совпадении всех сетевых кадров: проверяется максимальное соответствие композиции и поведения, известные отличия перечислены здесь.
