# Пешая доступность в Москве и ближнем Подмосковье

Страница `/?data=api#address-access` открывается из API-атласа по ссылке «По адресу». Поиск выполняется по локальному каталогу домов, полученному из снимка OSM, и уточняется выбором конкретного здания. Для запроса поиска используется тело POST, чтобы строка адреса не попадала в URL журнала доступа.

## Воспроизведение данных

Используй полный экстракт Geofabrik `central-fed-district-261107.osm.pbf`, фрагмент `moscow-bbox-261107.osm.pbf` из поставки московского графа Valhalla и пакет `moscow-urban-2026-11-10.4`. Границы графа по долготе и широте — 36.62–38.15 и 55.04–56.12. SHA-256 фрагмента — `924d706c7d8142f375c36b22bcb3473a61093a31afba93f7b0dbeb66047cccf0`. [Geofabrik](https://download.geofabrik.de/russia/central-fed-district.html) · [OpenStreetMap](https://www.openstreetmap.org/copyright)

```sh
mkdir -p data/processed/moscow-address
osmium getid -r central-fed-district-261107.osm.pbf r51490 \
  -o data/processed/moscow-address/oblast.osm.pbf
python apps/api/scripts/prepare_moscow_address_catalog.py \
  moscow-bbox-261107.osm.pbf data/processed/moscow-address/oblast.osm.pbf \
  data/bundles/moscow-urban-2026-11-10.4 data/processed/moscow-address/catalog.sqlite
python apps/api/scripts/prepare_moscow_district_access.py \
  data/bundles/moscow-urban-2026-11-10.4 --all
```

Для отдельных территорий можно передать несколько точных названий через `--name`. Сборка использует `osmium`, `shapely` и `pyproj` из среды подготовки геоданных. Для Python также должны быть доступны пакеты API и движка. API читает каталог из `A2_ADDRESS_CATALOGUE` или `data/processed/moscow-address/catalog.sqlite` относительно рабочей директории. `A2_ADDRESS_ROUTER_URL` по умолчанию указывает на `http://valhalla:8002`. Для результатов округов и районов API читает соседний `districts.json`.

Снимок содержит 135 064 записи адресов Москвы и 197 320 записей адресов области. Каталог включает 458 записей больниц, 2 806 школ, 3 634 детских садов, 369 колледжей, 427 вузов и 1 143 записи станционных подходов и входов. Записи станций могут представлять разные линии, платформы и входы одного комплекса. Адреса и учреждения отражают наблюдаемое покрытие OSM.

## Расчёт

Valhalla проверяет до 12 ближайших записей каждой категории в окне поиска. Результат использует минимальное найденное время среди проверенных записей и отдельно получает геометрию маршрута. Статический профиль использует скорость 5 км/ч. Координаты здания и учреждения привязываются к пешеходному графу. Если источник даёт только координаты объекта или платформы, результат помечается как подход. Локальная привязка предполагаемого входа метро к станции выполняется по близости и требует сверки. Фактический режим работы учреждений и внутренние переходы не проверены.

Индекс категории рассчитывает штатная функция движка. В Москве H = 60 минут. Для части адресов области H получен из границы населённого пункта по тегам OSM и утверждённым диапазонам площади. Если подходящая граница отсутствует, API возвращает время маршрута и пустой индекс. Общий индекс адреса использует выбранные приоритеты из конфигурации продукта. В текущем локальном сценарии запрос выполняется непосредственно через API, районные результаты публикуются пакетной командой.

В районном расчёте используются исходные точки московского пакета и веса GHSL 2025. Для округов применяются опубликованные доли населения ячеек. Для границ районов население пересечённой километровой ячейки распределяется пропорционально площади. Индексы категорий усредняются по весу доступных ячеек с отдельным показом покрытия. Общий результат публикуется при наличии маршрутов по всем восьми категориям для всего учтённого веса. Точки с отсутствующим входом сохраняются в знаменателе покрытия. Для муниципалитетов области потребуется сопоставимый слой ячеек населения.

## Расширение на Московскую область

Областной пакет использует тот же экстракт Geofabrik от 7 ноября 2026 года. Для него заново собран граф Valhalla 3.5.1 в пределах 35.0685–40.2847° в. д. и 54.1757–57.0385° с. ш. Прямоугольник покрывает границу Московской области с запасом для маршрутов через соседние территории. В поиск адресов входят точки внутри границ Москвы и области. Геометрия и полнота адресов и объектов зависят от снимка OSM. [Geofabrik](https://download.geofabrik.de/russia/central-fed-district.html)

Границы муниципалитетов берутся из отношений OSM с `admin_level=6` и принадлежностью к области. Тайл R3 C21 слоя GHSL GHS-POP R2023A E2025, 100 м, полностью покрывает область. Его архив проверяется по SHA-256 из манифеста проекта. [GHS-POP R2023A](https://human-settlement.emergency.copernicus.eu/ghs_pop2023.php) · [Перечень органов местного самоуправления](https://mosreg.ru/pravitelstvo/podvedomstvennye-organizacii/organy-mestnogo-samoupravleniya)

Областной муниципальный индекс оценивает пешую доступность больниц, школ и детских садов с одинаковыми весами. Центры пикселей GHSL распределяются по муниципальным границам. Из населения внутри городских границ с определённым H берётся до 16 репрезентативных точек на муниципалитет по равным квантилям накопленного населения, упорядоченного пространственно. В каждой точке применяется утверждённый городской индекс категории с H соответствующего города. Муниципальное среднее взвешено по населению. Общий индекс использует точки, для которых доступны все три категории. В знаменателе покрытия сохраняется всё население GHSL внутри муниципалитета, включая население вне городских границ с определённым H. Интерфейс показывает оценку по покрытой части и число расчётных точек. Категории метро, МЦД и МЦК доступны в адресном расчёте.

### Подготовка областного пакета

```sh
folder=data/processed/moscow-oblast
mkdir -p "$folder"
printf '%s\n' '35.0685,54.1757,40.2847,57.0385' > "$folder/bbox.txt"
osmium extract --strategy smart -S types=multipolygon,restriction \
  --bbox="$(cat "$folder/bbox.txt")" --set-bounds central-fed-district-261107.osm.pbf \
  --output "$folder/moscow-oblast-261107.osm.pbf"
# Скопировать valhalla.json из существующей поставки московского графа в $folder.
docker run --rm --network none --memory 7g \
  --mount "type=bind,source=$PWD/$folder,target=/data" \
  ghcr.io/valhalla/valhalla@sha256:4ac3d13d1019f9a130e9e6b6924c16ea55da0fa51e3653039152e33ad4095661 \
  valhalla_build_tiles -c /data/valhalla.json /data/moscow-oblast-261107.osm.pbf
python apps/api/scripts/prepare_moscow_address_catalog.py \
  "$folder/moscow-oblast-261107.osm.pbf" data/processed/moscow-address/oblast.osm.pbf \
  data/bundles/moscow-urban-2026-11-10.4 "$folder/catalog.sqlite" --bbox-file "$folder/bbox.txt"
cp data/processed/moscow-address/districts.json "$folder/districts.json"
# Запустить valhalla_service с новым графом и скачать GHSL R3 C21 по манифесту.
A2_ADDRESS_CATALOGUE="$folder/catalog.sqlite" \
  python apps/api/scripts/prepare_oblast_municipal_access.py "$folder/ghsl-c21.zip" \
    --router http://waydex-oblast-router:8002
```

Для запуска API укажи `A2_ADDRESS_CATALOGUE=data/processed/moscow-oblast/catalog.sqlite` и `A2_ADDRESS_ROUTER_URL=http://waydex-oblast-router:8002`. Снимок районов Москвы из первого пакета сохраняет происхождение своих результатов. Расширенный граф применяется к новым адресным расчётам.

Проверенный локальный пакет содержит 386 981 адресную запись Московской области. Для 128 604 определён H по городской границе. Из 56 муниципалитетов 34 получили общий индекс по выборке из покрытых точек. Для 22 муниципалитетов в этом снимке нет пригодной городской границы для выбора H. В браузере проверены адресные расчёты в Коломне, Дубне, Орехово-Зуеве и Серпухове, их муниципальные карточки, состояние без общего индекса в Лотошине и прежний индекс Арбата.

## Серебряные Пруды. Больница на Школьной

В базовом каталоге в пределах посёлка отсутствовали объекты категории «больница». Добавлен ориентир у входа по адресу Школьная улица, 4. По этому адресу Минздрав Московской области указывает хирургическое отделение Серебряно-Прудской больницы. Координаты 54.469583, 38.718206 взяты из отметки входа на карте адреса. Valhalla привязывает конечную точку к Школьной улице примерно в 22 м от ориентира. Двери отдельных отделений и последний участок от улицы до двери требуют уточнения. ## Адресный атлас и расчёт по границе

Режим «По адресу или точке» в атласе принимает `mode=walk`, `mode=car` или `mode=pt`. По умолчанию сохраняется пеший расчёт. Для авто используется статическое время движения без пробок и поиска парковки. Для точек в ЗАТО необходимы подтверждённые условия автомобильного доступа. Пеший индекс ЗАТО по-прежнему использует правила КПП.

Для категорий «Торговые центры» и «Автобусные остановки» расширьте рабочую копию каталога из того же экстракта OSM. Утилита проверяет SHA-256 снимка и заменяет только записи двух новых категорий. Остановки берутся из обозначений остановок и пассажирских платформ. Пешее время считается по сети до подхода к остановке.

```sh
base=data/processed/moscow-oblast-zato-voshod
staged=data/processed/moscow-oblast-address-v2
mkdir -p "$staged"
cp "$base"/{catalog.sqlite,localities.json,districts.json} "$staged/"
python apps/api/scripts/extend_address_destinations.py "$staged/catalog.sqlite"   data/processed/moscow-oblast/moscow-oblast-261107.osm.pbf
A2_ADDRESS_CATALOGUE="$staged/catalog.sqlite"   python apps/api/scripts/prepare_moscow_district_access.py data/bundles/moscow-urban-2026-11-10.4 --all
```

Укажите путь к расширенному каталогу через `A2_ADDRESS_CATALOGUE`. Для районов учитываются только исходные точки внутри границы. Доля населения пограничной ячейки сохраняется в знаменателе, даже если её исходная точка снаружи. Цели маршрутов могут находиться в соседнем районе. Городской районный индекс сохраняет исходный набор категорий. Новые категории доступны в адресном расчёте.

### Пилот адресного общественного транспорта

Нужен отдельный Valhalla 3.5.1 с графом из того же OSM-снимка и принятым GTFS наземного транспорта Москвы `mos-ground-transport-gtfs-20261110`. Обрабатываются только выбранные автобусные маршруты. Окно расписания 1–30 ноября 2026 года, 4 ноября исключено. Время отправления принимается как местное московское. По каждой категории проверяются четыре ближайшие записи каталога. В результат входят поездки с подтверждённым автобусным участком. Полное время берётся из ответа маршрутизатора. Сравнение с другими маршрутами Москвы и области ограничено покрытием графа.

Для воспроизведения создайте отдельный рабочий каталог, чтобы не перезаписывать пеший граф. В конфигурации Valhalla укажите разные `mjolnir.tile_dir`, `mjolnir.transit_dir` и `mjolnir.transit_feeds_dir`. По возможности подключите базу часовых поясов через `mjolnir.timezone`.

```sh
python apps/api/scripts/prepare_address_transit_feed.py   data/processed/gtfs/mos_ground_transport.gtfs-20261110.gtfs-repair-v1.zip   /path/to/pilot/feeds/moscow
valhalla_ingest_transit -c /path/to/pilot/valhalla.json -j 2
valhalla_convert_transit -c /path/to/pilot/valhalla.json -j 2
valhalla_build_tiles -c /path/to/pilot/valhalla.json /path/to/moscow-oblast-261107.osm.pbf
```

Запустите сервис с этим конфигом и задайте `A2_ADDRESS_TRANSIT_ROUTER_URL` для API. Без этого профиля API вернёт причину недоступности. Подмосковье, метро, МЦД и МЦК как виды передвижения в пилоте отсутствуют. Станции метро, МЦД и МЦК доступны как цели поездки. Источник расписания — [манифест GTFS](../../../data/manifests/timetables/mos-ground-transport-gtfs-20261110.json).
