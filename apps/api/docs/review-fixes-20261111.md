# PR #35: исправления после независимого review

Ветка `work/backend`. Проверенная база — `origin/dev`
`232642eed956e8db31c38125b4e25b1ee00df4ee`, включённая merge-коммитом `807167b`.

## Исправления

- P1, provenance: источником признака синтетики служит проверенный canonical
  source снимка. Пропуск или `false` у `demo_model` больше не обходят opt-in,
  точный preset и маркировку результата. Проверяются hash, QA и verified evidence.
  Все ветки возврата результата, включая private-car-only и неизвестное публичное
  расписание, получают модельные ограничения и `ranking_eligible=false`.
- Сценарий сверяет provenance сохранённой базы с загруженным снимком. Старая база
  без обязательной маркировки или с разрешённым рейтингом отклоняется с 409.
  Новая сторона сравнения наследует запрет рейтинга независимо от наличия меток
  в плане. Числа и immutable baseline не переписываются.
- P2, группы: каждый дочерний запрос проверяется до записи группы и постановки
  задач. Неподдерживаемое разбиение точного пресета возвращает 422
  `ANALYSIS_GROUP_CATEGORY_REQUEST_UNSUPPORTED`. Полный опубликованный пресет
  продолжает работать через `/analyses`; группы с опубликованными дочерними
  пресетами выполняются обычным worker. Повторная попытка старой несовместимой
  группы также не создаёт работу. Нового обходного режима авторизации нет.
- Четыре ранее падавших архитектурных проверки приведены к уже принятому коммиту
  `3d225a2`: отдельная точная extension fixture для групп, а не замена исторического
  эталона. Сохранены проверки привязки параметров SQL и транзакций; добавлены
  отрицательные проверки удаления session scope и изменения transaction options.
  Три пустые строки в старых примерах документации исправляют format check.

## Открытая зависимость FRONTEND

Текущий клиент из `dev` отвергает HTTP capabilities (`analysis_presets`), грузовое
предложение и результат (`handling_changes`). Перегенерированные схемы принимают
эти DTO, но это не подтверждает отображение интерфейса. FRONTEND должен обновить
схемы, точный выбор пресета, представление обработки груза и маркировку всех
модельных снимков. Конкретная передача и regression gate:
[frontend-demo-handoff.md](frontend-demo-handoff.md).

PR-wide P1 API → UI остаётся открытым до этого обновления. Полная матрица
24 baseline / 21 сценарий через собранный runtime и браузер здесь не подтверждена.
Проверка отдельных ML2 artifacts и TEST_ONLY HTTP fixtures её не заменяет.
Внешние платные провайдеры не вызывались.
