# Миграции PostgreSQL

BACKEND настраивает Alembic после появления API. SQLAlchemy 2 и asyncpg используются в инфраструктуре миграций. Приложение работает через параметризованный raw SQL с asyncpg. Первую ревизию проверяем применением к чистой PostgreSQL 17 и повторным запуском `upgrade head` в отдельной тестовой БД или схеме. Здесь пока есть только инструкция.
