# Методики и открытые решения
Все формулы пока отложены по прямому указанию пользователя. Даже выражения из исходного DOCX не активны. До утверждения доступны исходные метрики и status=methodology_pending, value=null.
| ID | Нужно решить | Владелец |
|---|---|---|
| M01 | Городская пассажирская формула, классы площади/H, веса, пропуски | ML1 + координатор |
| M02 | Межгород: окно, нормирование времени/частот, объединение узлов | ML1 + BACKEND |
| M03 | Грузовые индексы города и межгорода, совместимость, срочность | ML1 + ML2 |
| M04 | Трубопроводы: применимость и нормирование по продуктам | ML1 + ML2 |
| D01 | Растр населения, границы, область поиска здания, входы | ML2 |
| D02 | Источники расписаний и грузовых ограничений, API/квоты/даты | ML2 + BACKEND |
| U01 | Последний обратный рейс, пороги доступности, рейтинг/цвета | Координатор + ML1 |
| A01 | LLM/API доступ, лимиты, модель | BACKEND |

Добавление формулы: отдельный документ с единицами и примерами → согласование → версия конфигурации → реализация ML1 → контрольные проверки → контракт BACKEND → UI. Запрещены default H, fallback к старым профилям и незаметное изменение сохранённых runs.
