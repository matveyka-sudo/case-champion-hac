# Данные
Городские пассажиры: границы трёх городов/районов, сетка, здания/вода, население, девять категорий с формой собственности, входы, транспортная сеть и расписания.
Городские грузы: реальные производственные площадки/склады, совместимые узлы, допустимый грузовой подъезд. Юридический адрес ФНС не доказывает местонахождение производства.
Межгород: справочник городов/субъектов, столицы для пассажиров, основные грузовые узлы, направленные связи. Целевой охват всей России не означает наличие полных данных.
Трубопроводы: продукт, узлы приёма/сдачи, направление, состояние действующий/проектный, мощности/объёмы с периодом и единицами. Транзит отдельно от подключения.

Все источники с A2 из ТЗ должны иметь роль в реестре: Точно (связность, региональный сборник/ВРП, населённые пункты, БДМО), АСОП, Росморпорт, OSM/Geofabrik, OurAirports, реестр и статистика Росавиации, GeoNames, ЕМИСС, Росстат регионы/демография, ФНС, ФИАС/ГАР, стратегия и инфраструктурные проекты Правительства, Электронный бюджет, Росинфра, Минприроды, Росгидромет. Часть — контекст, не коэффициенты индекса. Точные ссылки и ограничения: reference/TZ_2026-11-07.md.
Дополнения: GHSL/WorldPop для населения, isDayOff, погодные данные, маршрутизаторы и расписания, операторы трубопроводов. Требуются проверка лицензий, ключей, квот и полей. Статистика Точно не заменяет расписание; погода сама по себе не даёт задержку.
Raw неизменяемы; accepted snapshot публикуется после QA. Версии, хэши, происхождение, география, период и неизвестные поля обязательны. Нет данных не равно отсутствию пути. Состояния measured/estimated/demo не смешиваются. Большие raw и секреты не коммитить.
