# BACKEND — первый версионированный контракт

Реализуйте канонический `AnalysisProfile` и его выдачу через `GET /api/v1/profiles/{profile_id}/versions/{profile_version}`. Получайте P1 из утверждённого TOML, проверяйте поля и возвращайте `profile_not_found` для отсутствующей ревизии. Начните с согласования типов времени и идентификаторов с ML1 и ML2. Договоритесь с DEVOPS о подключении workspace-пакетов.

Готово, когда endpoint возвращает утверждённую конфигурацию P1, валидирует вход и выдаёт документированные ошибки. Тесты проверяют корректный ответ, неизвестную ревизию и невалидный профиль. Экспорт OpenAPI и JSON Schema воспроизводим и опубликован в `contracts/generated/`. Передайте FRONTEND и ML2 схему, URL и порядок регенерации. После первого контракта добавляйте подключение asyncpg и Alembic по мере появления сохраняемых данных.
