# ML2

Ветка work/ml2. Пути: packages/data_pipeline/, data/, ml/.

Источник: ../PRODUCT_SPEC.md; контракты ../../packages/contracts/specs/README.md.

Реестр всех A2-источников и ролей, три города, сетка/население, девять категорий, расписания, предприятия и грузовые узлы, трубопроводы. Подтвердить фактическое покрытие API и ограничения.

Зависимости: BACKEND: schema snapshot; ML1: требования к сети и календарям.

Приёмка: QA координат, ключей, календарей, совместимости и населения; provenance; unknown не отсутствие.

Передача: commit, пути, команды/результаты проверок, контрактные изменения и ограничения. Формулы реализуются по FORMULAS.md и config/product.json; данные проверяются отдельно.
