# ML2 — первый версионированный snapshot расписаний

Соберите подтверждённые источники для P1. Начните с КППК, затем проверьте автобусный слой и пешие связи. Используйте исходные копии, журнал версий и действительные календарные интервалы. Согласуйте ключи, покрытие и формат Parquet с BACKEND и ML1. При неполных источниках явно определите предел первого snapshot.

Готово, когда ML1 получает manifest, неизменяемые таблицы и контрольные суммы, а правила преобразования воспроизводимы. Для каждого направления, режима и нужного периода подтверждено покрытие либо указан конкретный пробел. Проверены ссылки, остановки, ночные времена и исключения. Передайте контрольные поездки с источниками и статусами. После передачи данных согласуйте `get_profile`, `simulate_scenario` и набор A2-evals. Эксперимент с обучением рассматривайте после получения пригодных данных и рабочих результатов MVP.
