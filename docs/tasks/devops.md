# DEVOPS — запуск среды с чистого checkout

Подтвердите переносимость окружения на runner GitHub Actions и проверьте PostgreSQL 17 в изолированном Compose-проекте. Используйте отдельный порт и том. Сохраните короткую инструкцию и результаты проверки в зоне DEVOPS. Собирайте от владельцев запросы на упаковку реальных `src`-пакетов в порядке зависимостей из архитектуры.

Готово, когда workflow проходит проверку lock, frozen-установку, `npm ci` и проверку Compose. PostgreSQL становится healthy, принимает подключение к целевой БД и перезапускается с тем же томом. README позволяет повторить проверку в отдельном worktree. Добавляйте Nginx и сервисы приложений после передачи рабочих entrypoints владельцами.
