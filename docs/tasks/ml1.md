# ML1 — первая проверяемая маршрутизация

Реализуйте earliest-arrival для одного OD-запроса к `DatasetSnapshot` с параметрами из `AnalysisProfile`. Постройте граф событий с явными состояниями посадки, ожидания, движения и пересадки. Согласуйте структуру результатов с BACKEND. Запросите у ML2 первую версию данных и передайте DEVOPS точный путь импорта будущего пакета.

Готово, когда известная цепочка возвращает полный `RouteResult` с источниками, сумма этапов даёт полное время, а повторный расчёт даёт тот же результат. Проверки покрывают ночное время `24:00+`, исключение календаря, продолжение в том же рейсе, недостаточный буфер пересадки и различие `partial_data`, `missing_data` и `no_path_in_window`. Синтетические контрольные входы помечены. Передайте BACKEND и ML2 публичный интерфейс и проверенные примеры для дальнейшего индекса и сценариев.
