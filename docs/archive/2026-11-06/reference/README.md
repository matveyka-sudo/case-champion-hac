# Входные материалы A2

Действующая спецификация продукта — «Техническое задание проекта A2», версия 1.1 от 06.11.2026, 18 страниц. Оригинал передан команде как `ТЗ_проекта_A2(1).pdf`. SHA-256 оригинала `a5be80001a0999cf0e817ed22d6b412a4f4e4450ac863534ce828e21380c24b4`. PDF содержит ссылки на материалы чата. Для общего доступа используйте оригинал, переданный в согласованном командном канале, и сверяйте хэш. В публичном репозитории зафиксированы рабочие требования и ссылки на страницы в [матрице изменений](../ACCEPTANCE.md#изменения-по-тз-11).

O — требования организаторов. U — решения пользователя. R — рекомендации ТЗ. D — допущения, которые предстоит подтвердить. F — проверенные факты в пределах указанных материалов. Метки функций F01–F12 обозначают требования продукта отдельно от маркировки фактов. Реестр решений D1–D4 ведётся в [плане](../ML_PLAN.md#открытые-решения).
