# Входные материалы A2

Файлы скопированы из локального исследовательского пакета в редакции 2.0 от 6 ноября 2026 года. Исходные байты сохранены. В таблице указана роль каждого документа.

| Файл | Что из него берём |
| --- | --- |
| [Расширенное ТЗ U5](U5_Расширенное_ТЗ_A2.pdf) | Постановка задачи, результаты сдачи и проверка использованного результата ИИ. |
| [Презентация U2](U2_Презентация_кейсов.pdf) | Сроки и формат сдачи. |

| [Исследование команды](A2_Исследование_и_план_команды.docx) | Источники, расчётная методика, гипотезы и план проверок. |
| [Матрица требований](Матрица_требований.csv) | Привязка требований к источникам и предложенным решениям. |

Для ролей, структуры, PostgreSQL, модели-кандидата и первого этапа разработки действуют текущие [архитектура](../ARCHITECTURE.md) и [владение](../OWNERSHIP.md). Статус транспортных наборов и пробелы собраны в [DATA.md](../DATA.md).
