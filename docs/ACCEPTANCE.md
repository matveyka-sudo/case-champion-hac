# Приёмка подготовки
- config/product.json отражает четыре блока, три города, девять категорий, шаг 15 мин, сетку 1 км и отложенные методики.
- python3 scripts/check_product_config.py проходит без сторонних зависимостей.
- frontend/: npm ci, npm run build, npm run lint. Это проверка starter, не готового продукта.
- Python: uv lock --check; установка и проверки существующего workflow сохранены.

# Приёмка будущей реализации
1. Ближайший объект выбран по полному времени; сумма legs совпадает с total, ожидание не посчитано дважды.
2. После переноса точки население не дублируется; zoom не меняет выборку. Грузовые объекты не взвешиваются населением.
3. API failure/unknown не превращается в нулевой индекс. До утверждения методики score=null и рейтинг по score недоступен.
4. Девять категорий, три режима; нет такси, каршеринга, цен и достопримечательностей.
5. Межгород узел → узел, направления и часовые пояса корректны; кодшеринг не удваивает частоту.
6. Грузовая совместимость подтверждена; трубопроводный транзит не означает подключение, мощность системы не равна мощности пары.
7. «Проверить сценарий» запускает отдельный пересчёт только предложенного сценария. До проверки численного эффекта нет.
8. AI не придумывает население, поток, маршрут, время или эффект; форма работает при сбое LLM.
9. Рейтинг только сопоставимых результатов, без экрана сравнения территорий. До/после сценария сохраняется.
