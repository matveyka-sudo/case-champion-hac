# Приёмка итогового ТЗ и реализации
## Подготовка dev
Конфигурация совпадает с FORMULAS, модель Flash и версии заданы; python3 scripts/check_product_config.py и git diff --check проходят. Существующий frontend не меняется. Реальные API/графы не объявляются проверенными по одному наличию документации.

## Данные и интеграция
1. Missing API, incomplete timetable и confirmed no-route — разные результаты; unknown не превращается в 0. Полный территориальный индекс блокируется пропуском положительного веса. Zero denominator и τ без достижимых пар типизированы.
2. Сетка стабильна при zoom; вода/ячейки без зданий исключаются с учётом потерь; районы не дублируют население; объекты за границей города допускаются.
3. ГТFS exceptions, service times >24:00, разные зоны отправления/прибытия, даты вне покрытия, кодшеринг, обратное направление — отдельные fixtures. Поиск не обрывает достижимый путь просто из-за неполной выгрузки.
4. Traffic wrong direction/graph version/stale live отклоняется; static не подписан typical; schedule bus не штрафуется пробками дважды.
5. Эталон собирает смешанный путь; учитывает обязательный переход, не initial wait; partial reference исключён из полного рейтинга. Нельзя выбрать wait одного рейса и path другого.
6. Freight совместимость и направление подтверждены; неизвестная обработка не даёт полного delivery score. Pipeline не входит в общий индекс и не восстанавливается из линии транзита.
7. Пересчёт сценария только после кнопки; fixed snapshots/weights/H/τ; изменения распространяются по рейсу, ухудшения и feasibility видимы. Новый путь не даёт Infinity.
8. Flash: русский запрос, read-only tool, ошибочный JSON, неизвестный tool, prompt injection в документе, timeout и fabricated metric_id. Во всех случаях данные/расчёт доступны, непроверенные числа не публикуются.
9. E2E: 4 analysis_kind, выбранная пара/район, job progress, result/error/partial, карта и карточка, сценарий; demo не попадает в production rating. Сравнение территорий отдельным экраном не добавляется.
10. Проверка бюджета на реальном пилоте: длительность построения графа, пик RAM, время первого анализа/кеша, количество внешних запросов. Отчёт измерений вместо обещанного неподтверждённого SLA.

Команды UI: npm ci, npm run build, npm run lint, npm test. Python: uv lock --check закреплённой версией uv, затем проверки реализованных модулей. Live API тесты — отдельно с ключом; их пропуск не помечается PASS.
